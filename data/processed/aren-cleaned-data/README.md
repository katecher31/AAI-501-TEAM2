# Data Cleaning – Aren Sinaei

This folder contains my independently cleaned version of the AI Sec Watch Dataset v4.0, prepared as part of the AAI-501 Team 2 project.

## Work Performed

- Filtered the original dataset to include vulnerability records only.
- Reviewed data quality, missing values, and duplicate records.
- Removed records with an Info severity label.
- Prepared selected features for machine learning.
- Handled missing values in the selected modeling features.
- Exported the cleaned dataset for team review and comparison.

## Notes

This version represents my individual contribution to data preparation and is available for team review and comparison before establishing the shared finalized dataset.

The original dataset is preserved in `../../raw/`.
